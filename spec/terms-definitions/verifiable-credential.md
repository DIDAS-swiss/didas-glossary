[[def: verifiable credential, verifiable credentials, VC, VCs, verifizierbarer Nachweis, attestation vérifiable, attestato verificabile]]

~ A tamper-evident [[ref: credential]] whose authorship by an [[xref: toip-glossary, issuer]] can be cryptographically verified. Verifiable credentials can be used to build verifiable [[xref: toip-glossary, presentation]]s, which can also be cryptographically verified. The [[xref: toip-glossary, claim]]s in a credential can be about different [[xref: toip-glossary, subject]]s.

~ In the swiyu trust [[ref: ecosystem]], verifiable credentials are issued, held and presented using the **IETF SD-JWT VC** format (Selective Disclosure JWT-based Verifiable Credentials), as profiled by the [Swiss Profile VC](https://swiyu-admin-ch.github.io/specifications/swiss-profile-vc/). `swiss-profile-vc:1.0.0` contains [SD-JWT VC Draft 15](https://www.ietf.org/archive/id/draft-ietf-oauth-sd-jwt-vc-15.html) over SD-JWT ([RFC 9901](https://www.rfc-editor.org/rfc/rfc9901.html)), with [Token Status List Draft 20](https://www.ietf.org/archive/id/draft-ietf-oauth-status-list-20.html) and OCA 1.0. [Swiss Profile Issuance](https://swiyu-admin-ch.github.io/specifications/swiss-profile-issuance/) states that the Credential Format Profiles "ISO mdoc" and "W3C VCDM" are **NOT SUPPORTED**.

~ ToIP reference: [[xref: toip-glossary, verifiable-credential]]

~ Supporting definitions:

~ [W3C VC]: A verifiable credential is a tamper-evident credential that has authorship that can be cryptographically verified.
